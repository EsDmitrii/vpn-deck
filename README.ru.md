# VPN Deck

[English](README.md)

Плагин для Decky Loader, позволяющий управлять VPN (AmneziaWG и VLESS) на Steam Deck.

## 📋 Описание

**VPN Deck** — VPN прямо из игрового режима Steam Deck:

- Импорт: `.conf` AmneziaWG, ссылки `vpn://` и `vless://`, JSON sing-box
- Один переключатель на конфиг, работает один конфиг за раз
- Статус: внешний IP, скорость, handshake
- Переживает сон и смену Wi-Fi, подключается после перезагрузки

Нужен root.

### ⚠️ Важно: Ограничения

**В версии 2 плагин не управляет интерфейсом `awg0`.** Управляются только конфиги, добавленные через плагин (интерфейсы вида `vd-<имя>`).

Конфиги, импортированные через плагин, хранятся в `~/.local/share/vpn-deck/configs`; для AWG создаются симлинки в `/etc/amnezia/amneziawg/`. Бинарники AmneziaWG и sing-box входят в релиз плагина, отдельная установка не нужна.

## Изменения между v1 и v2

| | v1 | v2 |
|---|----|----|
| **Интерфейс** | Управлял только одним интерфейсом `awg0` через `systemctl` | Интерфейсом `awg0` **не управляет**. Только конфиги, добавленные через плагин (интерфейсы `vd-*`) |
| **Настройка** | Конфиг нужно было настраивать вручную в Desktop Mode (сборка amneziawg-go/awg-quick, создание `awg0.conf`, симлинки) | Конфиги импортируются из UI (файл `.conf`). Бинарники входят в релиз |
| **Конфиги** | Один конфиг (`awg0`) | Несколько конфигов с именами `vd-<имя>` |

Если вы использовали v1 с `awg0`, после обновления на v2 этот интерфейс плагин больше не поднимает и не останавливает. Чтобы управлять VPN через плагин, импортируйте конфиг заново через «Импортировать конфиг».

## 📥 Установка плагина

Устанавливайте плагин **только из официальных релизов** на GitHub.

**Перед удалением плагина или установкой новой версии выключите VPN в самом плагине** (переключатель у активного конфига поставьте в «выкл»). Иначе обновление или удаление могут завершиться с ошибкой.

**По ссылке (проще всего):** Decky Loader → настройки → «Developer» → «Install Plugin from URL» → вставьте

```
https://github.com/mrwaip/vpn-deck/releases/latest/download/vpn-deck.zip
```

**Из файла:** скачайте `vpn-deck.zip` из [Releases](https://github.com/mrwaip/vpn-deck/releases), скопируйте на Steam Deck, Decky Loader → настройки плагинов → «Установить плагин» → укажите путь к файлу.

**После установки:** откройте плагин в игровом режиме → «Импортировать конфиг» → выберите файл (например, из папки «Загрузки»). После импорта конфиг появится в списке и его можно включать/выключать.

### Какой файл нужен

- AmneziaVPN: ссылка `vpn://` (сохраните в `.txt`) или экспорт «AmneziaWG native format» (`.conf`)
- VLESS: ссылка `vless://` в `.txt`
- sing-box: `.json` с одним `tun`

### Как переслать конфиг на Steam Deck

Файл нужно каким-то способом перенести на Deck, чтобы выбрать его в плагине:

- **LocalSend** — установите приложение на телефон/ПК и на Deck (из Discover в Desktop Mode). Отправьте файл на Deck; он окажется, например, в «Загрузки». Ссылку можно отправить текстом и сохранить в `.txt`.
- **Desktop Mode + браузер** — переключитесь в режим рабочего стола, откройте браузер, скачайте конфиг (или сохраните из почты/мессенджера) в папку «Загрузки». В игровом режиме в плагине укажите путь к этому файлу (например, `/home/deck/Downloads/имя.conf`).

## Использование

- **Импорт конфига** — кнопка «Импортировать конфиг», выбор файла. Плагин покажет, что это за конфиг (AWG, VLESS REALITY…). Имя конфига — до 12 символов (буквы, цифры, `_`, `=`, `+`, `.`, `-`).
- **MTU** — если туннель поднялся, но ничего не открывается, импортируйте конфиг заново с «MTU 1280».
- **Включение/выключение** — переключатель рядом с именем конфига.
- **Удаление конфига** — «Удалить конфиг» под нужным конфигом (интерфейс будет остановлен).
- **Ошибки** — раздел «Ошибки»: просмотр истории и кнопка «Очистить историю ошибок».

## Безопасность

Плагин работает от root, поэтому команды `PostUp`/`PreUp` из ссылок `vpn://` не импортируются, а в JSON sing-box запрещено открывать порты в сеть и писать файлы.
